# QA and operational artifacts

Store dated ticket-linked review evidence here. Use the ticket QA section for
small reviews and `.team/templates/release-review.md` for release/operational
work. Findings cite agreed criteria or documented regressions; unknown behaviour
routes to Product Owner. Distinguish actual execution from historical reports.
Do not include credentials, connection strings, private photos or signed URLs.

README retains the application setup, existing verification commands and deployment
limits. Bootstrap adds no CI/CD, infrastructure, secrets or production changes.
No production release has been authorized by creation of this directory.
